## 🛠️ Competências e Tecnologias Aplicadas

* **Microsoft Power BI:** Construção de dashboards interativos e layouts focados em experiência do usuário (UX/UI).
* **Power Query (M):** Extração, transformação, tratamento e limpeza de dados (ETL).
* **Linguagem DAX:** Criação de medidas calculadas, indicadores (KPIs), inteligência de tempo (Time Intelligence) e colunas calculadas.
* **Modelagem de Dados:** Esquema Estrela (Star Schema), relacionamentos e otimização de performance.
